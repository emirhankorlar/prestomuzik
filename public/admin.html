Bu panel GitHub üzerinden çalışıyor. Giriş için repoya yazma izni olan bir GitHub token girin. Token hiçbir yere kaydedilmez, sekmeyi kapatınca silinir.

Token nasıl alınır?
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → bu repo
  3. Permissions: Contents: Read and write, Actions: Read and write
  4. Oluşan github_pat_… değerini buraya yapıştırın
